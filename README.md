# Igor Esteves Camionetes — prévia organizada

## Estrutura
- `index.html`: estrutura e conteúdo das seções.
- `css/style.css`: estilos, cores, responsividade e animações visuais.
- `js/script.js`: menu, animação do hero, filtros do estoque e modal dos veículos.
- `assets/`: pasta reservada para imagens reais que serão adicionadas depois.

## Como visualizar
Abra `index.html` no navegador. Para testar como um site local, também pode usar a extensão Live Server do VS Code.

## Antes de publicar
- Substituir o número provisório do WhatsApp em `js/script.js` (`const WA`).
- Atualizar fotos, estoque, preços e informações de contato com dados reais da loja.
- Confirmar/remover depoimentos e demais conteúdos marcados como provisórios.

**Nota:** a estrutura, os textos, a identidade visual, as seções e os comportamentos existentes foram mantidos; o CSS e o JavaScript foram movidos para arquivos separados para facilitar manutenção.
